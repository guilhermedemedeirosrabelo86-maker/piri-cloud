# piri-cloud

A cloud project repository.

## Getting Started

### Clone this repository

```bash
git clone https://github.com/SEU_USUARIO/piri-cloud.git
cd piri-cloud
```

### Initialize a new local repository and push to GitHub

If you are starting from scratch locally, run the following commands:

```bash
git init
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/piri-cloud.git
git push -u origin main
```

> Replace `SEU_USUARIO` with your GitHub username (substitua pelo seu usuário do GitHub).
